# Henley High School homepage reproduction

Static reproduction of https://www.henleyhs.sa.edu.au/, using its actual homepage structure, green and white theme, Avenir fonts, logos, imagery, video and responsive navigation. Original content and assets remain attributable to their respective owners. This is an independent reproduction, not the official school site.

Run `python3 -m http.server 3000 --bind 0.0.0.0` from this directory. No installation or build is required. Other pages and search link to the official site. Authentication, analytics and translation integrations are omitted. Homepage assets are saved locally; no school backend is included.
